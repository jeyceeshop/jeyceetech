# Referentes visuales

Las 16 marcas se presentan como referentes de diseño, no como clientes, socios, patrocinadores ni certificaciones de Jey Cee. La propia sección de la web lo indica expresamente. Los nombres y logotipos son marcas de sus respectivos titulares.

McDonald's, Nike, Apple, Spotify, adidas, Samsung, Dior, Mercedes-Benz y Porsche:
