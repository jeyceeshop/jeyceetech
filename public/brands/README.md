# Referentes visuales

Logotipos de McDonald's, Nike, Apple, Spotify y adidas obtenidos de Simple Icons 11.15.0:
https://github.com/simple-icons/simple-icons/tree/11.15.0/icons

Los archivos SVG de Simple Icons se distribuyen bajo CC0:
https://github.com/simple-icons/simple-icons/blob/11.15.0/LICENSE.md

Los nombres y logotipos son marcas de sus respectivos titulares. Se muestran como referentes de diseño, no como clientes, socios, patrocinadores ni certificaciones de Jey Cee. La propia sección de la web lo indica expresamente.
